# TCL Home AC

Noctalia plugin with a Home shortcut, popup controls, bar widget and a standalone
Python companion for a TCL Home split air conditioner.

**Run `sh tcl-control/setup.sh` from a checkout before enabling.** Python packages
and credentials are stored in user XDG directories, outside the plugin runtime
copy, so plugin updates do not overwrite them.

See the [installation guide](https://github.com/ggmorais/noctalia-tcl-control#install),
[Portuguese documentation](https://github.com/ggmorais/noctalia-tcl-control/blob/main/README.pt-BR.md),
and [security notes](https://github.com/ggmorais/noctalia-tcl-control/blob/main/SECURITY.md).

Requires internet/TCL cloud. Tested on TAC-12CHTG2-INV; other models are unverified.
